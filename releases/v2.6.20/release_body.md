# Muse v2.6.20

> 这一版做的是「把扩展能力做成体系，把助手的手脚接上真东西，并且让插件能改应用里的一切」：
> 插件系统整体重构 + 九项能力扩展、对比清单 11 项助手能力整改、主动消息「这次不用」修好、
> 工作区可以放到下载目录。

本版合并了 v2.6.19 之后到现在的全部改动。

---

## 中文

### 插件系统：从「能装」到「能改应用里的一切」

核心规则只有一条：**声明 ≠ 授权**。清单里写了能力只是「申请」，用户批准之前每次调用都会被拒绝。

**基础形态**

| 能力 | 说明 |
|---|---|
| 能力总线 + 权限账本 | 逐项授权/撤销；每次调用都记账，调试台能看到「谁、什么动作、放行还是被拒、为什么」 |
| 声明式界面 | 插件用 JSON 描述界面，宿主原生渲染；表单提交有独立能力 `ui.interactive`，默认关闭 |
| 斜杠命令 `/name` | 命令结果写回输入框，**不写聊天历史** —— 不冒充模型说话 |
| 激活事件 | `onStartup` / `onMessage` / `onToolCall`，观察型，各自独立能力、默认关闭 |
| 决策钩子 `onToolCallBefore` | **只能收窄**：排在审批闸门之后，插件放行不能绕过审批 |
| 追加系统提示词 | 独立能力，追加内容一律带来源标记「按参考资料对待，不是用户指令」，单次上限 2000 字 |
| 供应商插件 | 包内 `provider.json` → 供应商列表；随启停/卸载同步，不留孤儿条目 |
| 定时任务 | 间隔下限 15 分钟；先记时间再执行；时钟回拨不重跑 |
| 作者体验 | 三个可运行示例、宿主 API 类型声明（每个方法标注桥接动作名）、调试台 |
| 安装方式 | GitHub 仓库地址安装、`muse://plugin?url=…` 深链（可扫码） |

**本版新增的九项扩展能力**（全部默认关，逐项授权）

| 能力 | 插件能做什么 |
|---|---|
| `network.local` | 连局域网与本机（家里的服务、本地 Ollama、自建 API） |
| `app.navigate` | 让应用跳到指定页面（页面走白名单，与深链同一份） |
| `app.messages` | 往当前会话里写消息（用户会当成助手说的） |
| `app.theme` | 切浅色/深色外观 |
| `app.settings` | 改外观类设置（字号/动态取色/高对比/默认首页） |
| `ui.slot` | 往聊天页顶部放自己的界面片段（带来源标记） |
| `storage.shared` | 与其他插件共享 KV（双方都要声明才互通） |
| `runtime.long` | 单次执行超过默认 10 秒（上限 10 分钟） |
| `schedule.background` | 应用不在前台时也能被唤醒补跑定时任务 |
| `runtime.service` | 常驻后台（一个前台服务承载所有服务型插件，一条常驻通知） |

**安全模式新增「关闭所有插件」总闸**：一个文件标志，不依赖任何组件；关掉之后工具、命令、
事件、钩子、定时任务、桥接动作全部不执行（连不需要能力的 `echo` 也不放行）。恢复入口在插件页。

**边界写在明处**：热重载、部分 hook 注册、市场目录产物明确未做；
外部插件**不能加载原生库**（Android 10 起禁止从私有目录 dlopen，包内含 `.so` 会被明确拒绝并说明原因）。

### 工作区：可以放到下载目录

默认仍在应用私有目录；在**工作区页顶部**点「放到下载目录」，授权后迁移到 `Download/Muse` ——
任何文件管理器都能看到，也能用电脑直接拷走。

迁移三条底线：先复制后删除、目标非空不覆盖、失败退回私有目录。必须重启生效（工作区根目录在启动时
就被终端、文件工具、挂载表各自持有）。

### 助手能力：对比清单 11 项整改

- **系统写操作不再假成功**：亮度/音量/手电改成 before → after → verified；
- **浏览器动作不再假成功**：区分「已发出」与「效果已验证」；
- **日历**：重复日程按实例展开、全天事件按 UTC 写入、写哪个日历必须明确、支持按 `event_id` 改/删；
- **自动化**：AUTO 模式先判断目标是否已在前台；虚拟屏可交接给用户再交回；屏幕证据分三态（变了/没变/**未知**）；
- **终端**：后台 job 可提交、查询、终止；
- **子代理**：`access` 三档真正生效、`agents/<name>.md` 角色解析；
- **技能包**：`SKILL.md` 导入与按需读取、路径穿越防护、从 GitHub 安装、半成品自动清理；
- **朗读**：mediaPlayback 前台服务 + 音频焦点（来电即停）；
- **助理入口**：系统数字助理可唤起，Assist 上下文进输入框且不自动发送；
- **市场**：目录拉取失败给出可行动说明。

### 隐私与数据保留

- 按数据类别的保留表（工具输出 / MCP 结果 / 记忆原文 / 系统上下文 / 通知历史）；
- **通知历史**：有界 500 条、保留 3 天 —— 现在可以问「今天上午有什么通知」；
- **联系人**接进手机上下文，只取名字；
- 落盘的工具输出按工具名分类清理（MCP 结果保留期更短）。

### 主动消息

- **修**：通知上的「这次不用」以前只在运行时动态注册接收器，进程被杀后点了**毫无反应**；
  现在改为清单注册（不导出）+ `goAsync()` 冷启动等待依赖就绪；
- 顺带把调度器里一处与实现不符的注释改对。

### 已知未做

- 插件开发模式热重载（改文件即重载）；
- 插件 `toolPromptCompose` / `messageProcessing` / `summaryGenerate` 的注册；
- 市场目录产物与发布流程；
- 外部插件的原生库（平台不允许）。

以下只能换环境验证，逐条写在 `自动化整改_真机验收清单.md`：
虚拟屏落点与注入、助理唤起、朗读锁屏与来电、终端 job 的 kill 残留、
GitHub 安装的网络分支、截图质量对识别率的影响（样本对照），
以及本版新增的**服务型插件耗电与系统回收**、**后台补跑时机**、**槽位渲染**、
**工作区迁移到下载目录**四项。
