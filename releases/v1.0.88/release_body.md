# Muse v1.0.88

本版本在 v1.0.87 基础上完成了全量功能审查修复和安全加固，进一步提升了系统的稳定性和安全性。

## 重点更新

### 安全与数据保护

- **PiiGuard 统一为 common PiiEngine**：将隐私保护功能统一到公共模块，提高代码复用性
- **SSRF 防护加固**：对 Accessibility/Browser/WebSocket 等组件进行 DNS rebinding 复核，防止服务器端请求伪造攻击
- **RootExecutor 参数白名单**：限制可执行命令范围，防止命令注入
- **JsSandbox 校验加强**：增强沙箱环境的安全性，限制危险操作
- **BackupCrypto 加固**：提升备份加密的安全性
- **ToolRouteExecutionGuard**：消除工具定义与执行的分裂问题

### 功能完善

#### 记忆系统
- **UI置顶并入system prompt注入**：支持将重要记忆置顶，并自动注入到系统提示词中
- **重要度筛选**：支持按重要程度对记忆进行筛选和排序
- **来源展示**：显示每条记忆的原始来源会话，增强可追溯性

#### 备份系统
- **三库打包**：自动备份将memory/facts三库纳入打包范围，确保数据完整性
- **一键恢复**：新增一键恢复功能，支持校验、回滚和FTS重建
- **密码加密导出**：本地导出采用密码加密，保护隐私数据安全

#### 聊天交互
- **跨会话转发**：支持将消息转发到其他会话，方便信息整合
- **长按加号收展**：优化长按加号菜单的展开/收起交互体验
- **/pin /reset 语义**：新增消息置顶和对话重置命令
- **气泡圆角可调**：用户可自定义消息气泡的圆角样式

#### 模型管理
- **多Key管理UI**：支持在同一界面管理多个API Key，方便切换使用
- **原生联网标签**：为支持联网的模型添加专属标识

#### 工具系统
- **skillpkg模板**：新增技能包模板功能，方便用户快速创建自定义技能
- **JS桥接**：支持JavaScript脚本与工具系统的桥接
- **子代理可取消**：子代理任务支持中途取消操作

#### 调度系统
- **每日总结时段配置**：用户可自定义每日总结的触发时间
- **Moment入口**：新增Moment功能入口，记录重要时刻
- **后台任务总控**：统一管理平台所有后台任务的启停

### 数据库更新

- **DB v97迁移**：在assistants表新增enabled列，默认值为1（启用），支持助手启停功能

### UI链路体验优化（26项）

- 聊天交互优化、记忆与会话优化、设置/助手/备份优化
- 修复多项界面显示问题和交互异常
