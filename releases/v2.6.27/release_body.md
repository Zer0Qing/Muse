# Muse v2.6.27

## 本次更新

### 联网搜索更准

- 修复了搜索时只按第一个关键词查找的问题；现在多个关键词会一起生效，中文词序和 `site:` 过滤都按你的输入来。
- 搜索供应商设置改成「列表 → 详情」：点进某个搜索服务后，可以直接配置 Key、测试连接并保存，不用再自己填接口地址。

### 记忆更稳定

- 修复了旧记忆反复出现在最近时间的问题，回忆内容现在按真实时间归位。
- 修复了记忆里删除、置顶后可能丢失或重复显示的问题。
- 修复了多轮对话后摘要被旧内容覆盖的问题，记忆更新更可靠。

### 阅读与选择更方便

- 「选择文本」现在打开整屏文字页，长按就可以复制、全选或搜索，不再需要在小气泡里慢慢拖选。

### 其他修复

- 修复了文件夹加入会话再删除后，会话计数显示为 -1 的问题。
- 小手机相关入口从首页、设置和搜索中统一收起，界面更干净。
- 修复了若干稳定性问题，升级和使用更顺畅。

# Muse v2.6.27 (English)

## What's New

### Better web search

- Fixed search only using the first keyword. Multiple terms, Chinese word order and `site:` filters now reach the search provider as written.
- Search provider settings now use a list-to-detail flow. You can add keys, test the connection, and save without manually entering a provider URL.

### More reliable memory

- Fixed older memories repeatedly moving to the most recent time slot; they now stay at their real time.
- Fixed pin, delete, and memory-page actions that could lose or duplicate content.
- Fixed stale summaries overwriting newer memory updates during long conversations.

### Easier text selection

- "Select Text" now opens a full-screen plain text page, so copy, select all, and search are available directly from the system long-press menu.

### Other fixes

- Fixed folder conversation counts showing -1 after adding and deleting a conversation.
- Removed mini phone entries from the home menu, settings, and search for a cleaner layout.
- Fixed several stability issues for smoother upgrades and usage.
