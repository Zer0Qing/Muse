# Muse v1.0.83

本版本自 v1.0.82 以来的完整改动如下。

## 稳定性与对话恢复

- 修复流式回复被旧的对话树快照覆盖，导致最新助手内容消失的问题。
- 等待中间消息写入完成，并在应用回到前台后从 Room 重新加载当前会话，提升切后台再回来时的恢复可靠性。
- 当结构化消息 part 缺少正文时，回退使用旧版消息内容，避免消息投影为空。
- 重整 ChatViewModel、消息投影、对话树和消息持久化链路，降低切换会话、重新进入页面和流式中断时的状态串线概率。
- 完善对话树排序、消息分支和历史消息恢复测试。

## 输入栏、底部面板与界面

- 修复三键导航栏遮挡底部面板末尾操作的问题，统一聊天输入栏和底部面板的导航栏、键盘 Insets 处理。
- 新增用户可控制的预测性返回设置，默认开启；关闭后立即执行普通返回行为。
- 加号菜单锚定到输入岛，不再出现覆盖全屏的白色遮罩，菜单内容支持滚动。
- 保留加号菜单三行布局：拍照预览与照片位于第一行，联网搜索与深度思考位于第二行，其余功能位于支持横向滑动的第三行。
- 调整聊天列表、消息气泡、主页和调试页面的布局，修复部分页面内容裁切、底部留白和返回后显示异常。
- 优化窗口、Dialog、BottomSheet 和通用 Insets 基础组件，改善不同导航模式下的显示一致性。

## 生成、工具与任务

- 关闭流式输出时改用 `completeText()`，避免结束阶段内容不完整。
- 对不兼容 thinking 与 `tool_choice` 的请求最多进行一次兼容重试，避免重复请求。
- 对大型工具集合按用户意图筛选工具 schema，同时保留显式请求全部工具的行为。
- 修复重复错误卡片和后台主动消息请求风暴，完善工具调用状态清理。
- 从完整的工具消息历史中恢复持久化任务计划，离开并重新进入会话后计划卡片仍能正确显示。
- 完善工具执行、群聊调度、后台任务以及委托任务的生命周期处理。

## 模型能力与视觉

- 补齐 Qwen3.5、DeepSeek OCR、GLM4.6 的模型能力识别。
- 保留视觉模型只返回 reasoning 内容时的有效输出，不再误判为空结果。
- 完善 ModelRegistry、ProviderCompat 及相关能力回归测试。

## UI 自动化与系统兼容

- 当设备未实现开发者设置 Intent 时，UI 自动化设置页安全回退，不再因为系统差异崩溃。
- 新增 UI 自动化相关 Intent 封装与测试。
- 修复调试日志、崩溃日志、安全模式和审计日志分享时使用非 Activity Context 导致的崩溃，统一通过安全的分享辅助类处理。
- 补充多语言自动化设置和设置页面资源，覆盖英文、西班牙文、日文、韩文、巴西葡萄牙文和俄文。

## 数据库与工程质量

- 补充消息投影、对话树、聊天设置、视觉桥接、任务计划、工具菜单和 BottomSheet 布局回归测试。
- 修复测试中的数据库迁移、消息持久化和布局边界问题。
- 更新 Detekt 配置与基线，改善多模块静态检查和 CI 严格校验的稳定性。
- 更新中英文 README 与版本说明。
