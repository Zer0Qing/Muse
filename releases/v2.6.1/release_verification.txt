This build includes (v2.6.0 -> v2.6.1)
--------------------------------------
Fixes
- Memory browser crash in "All" scope: main and sub-assistant memories are stored
  separately with independent numbering; same-numbered entries collided on list key.
- Occasional crash on app open when system animations are off (0-length transition
  produced an invalid seek fraction in NavHost).
- Delete your own messages directly from the quick action row.
- "All day" switch for proactive messages (start/end hour range could not cover 24h).
- Quick capture overlay focus fix.
- Daily automatic backup now includes settings (matching manual export / cloud backup;
  provider secrets still excluded).
- Assistant could not reach the embedded Python entry point: execute_python_script was
  missing from the built-in tool whitelist (filtered out before exposure), so the model
  kept hunting for an interpreter in shell/Node. Registered it; guidance pinned.
- Built-in JS execution always failed: JsSandbox circuit-state map used a null key,
  which ConcurrentHashMap rejects (NPE on every call). Fixed with a sentinel key.
- Tool search promised "available from your next call" for tools outside the assistant's
  own tool config, which then failed with "not exposed in this turn". Search now scoped
  to the assistant's visible set and states the reason when a tool must be enabled first.
- Pure card messages (plan/execution cards) no longer render the message quick action row.

New
- Embedded Python 3.14 runtime (execute_python_script; full stdlib, pip for pure-Python
  packages; plugins can opt into runtime=python).
- Global "force reasoning" switch.
- B12 unused-resource cleanup (176 drawables + 1098 keys across 7 locales; smaller APK).

Local candidate; publish flow executed locally (no CI). No silent replacement of any
already-public asset: v2.6.1 tag did not previously exist.
