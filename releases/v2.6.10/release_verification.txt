== 本版内容（2.6.6 → 2.6.10 累计，四个版本一次发出） ==

P0 修复
- 卡片自动高度只剩 38%：WebView 返回 CSS px，代码当物理像素又除了一次 density(2.625)
- 卡片与待办在严格模式下每张弹审批，30 秒不点自动拒绝，卡片直接消失 → 归为无副作用展示
- 工具名被正文污染（"…等一下.show_card"）导致整轮失败 → 仅在能对上本轮暴露工具时还原
- 工具参数是一整句人话时报"参数格式异常" → 按正文交付
- Responses API 工具结果字段写成 content，服务端要 output，回传结果那一轮必定 422 失败
- 已写出正文的回复不再为"声称调工具却没给调用"重试并丢弃内容

主动消息重建（2.6.9）
- 牵挂账本 pending_thought / 结果账 proactive_outcome / 亲密度 proactive_relation
- 移除 ProactiveScoreEngine、ProactiveMessageRunner、ProactiveMessageWorker
- 五档量级重排：安静 3 / 克制 6 / 标准 15 / 主动 24 / 黏人不设上限
- 新增重置（回默认档 + 清零当日额度）；安静时段生效；三表并入备份

界面
- 记忆支持长按多选批量删除（列表与时间轴同步，删完不跳回顶部）
- 输入栏过程扁条 + 消息流末尾常驻过程卡；步骤可折叠，失败标红
- 设置一级 7 组 → 11 组，多项选项归位，表情包升为独立页
- 渠道支持出站媒体（Telegram / 飞书 / QQ / 钉钉）；联系人会话流改气泡；失败错误码前置
- 头像 28→36dp；消息气泡跟随主题色

其它
- 上下文预算按系统提示 / 工具定义 / 输出预留 / 安全余量实际扣减
- 跨会话衔接、自定义搜索引擎、DeepSeek 搜索、显示助手名字开关（默认开）
- 新工具：note_thought（牵挂记账）、remember_preference（偏好沉淀）、tool_status（能力自查）、read_user_file
- 执行前通道预检：注定失败的工具在调用前就被拦下并给开通路径
- 会话待办落库；渠道接收器不再"永久死亡"；卡片状态 JSON 收敛到三个出口
- 备份补字符串集合类设置（朋友圈收藏、相册收藏）；会话滚动位置落盘
- 压缩阈值统一 20/15（长记忆 10/8）；工具默认可见范围上调
- 数据库 111 → 119（跨 8 个版本，含主动消息三表）
- R8 关闭优化 pass，保留混淆与资源裁剪，避开 MessageBubble 体量导致的 VerifyError
