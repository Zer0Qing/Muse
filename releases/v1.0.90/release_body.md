# Muse v1.0.90

本版本为全量整改收官版，合并审计—整改—复核多轮成果。

## 插件与市场

- 内置官方目录（museai.ltd），每目录带 sequence 防回滚。
- 插件版本与回滚：默认禁止降级，发行者交叉校验与信任库。
- 助手代写插件：草稿 + 用户显式签名启用，不执行未签名包。
- 离线签名工具与插件包校验（52 项契约用例）。
- ui-skin 皮肤包能力（仅 JSON / 资源，不注入 Compose）。

## UI 与可访问性

- 顶栏与「更多」菜单统一（裸图标 + 原生菜单卡片）。
- 组件收敛：删除死组件，替换为 SettingsSliderRow 等统一组件。
- 气泡皮肤接入渲染器。
- 修复固定高度承载文本导致的裁切与顶栏爆高问题（含 1.3x 字体缩放走查）。
- 重索引终态通知与入队回执。

## 安全与数据完整性

- 修复审批默认放行陷阱（未配置不再视为显式允许）。
- 记忆事实路由改为 (scope, id) 复合定位，消除跨分库同号事实串号。
- 工具风险台账单源化，覆盖 19 个注册器的一致性测试。
- SSRF 异步化、SPEAKING 看门狗、工具超时晚到结果门禁、定向检索分页。

## CI 护栏

- 组件收敛检查（CMP-11）。
- 翻译残留检查（I18N-02，5 语言包 0 残留）。
- 字体缩放裁切检查（A11Y-03，固定高度承载文本与无界 heightIn 两条规则）。
