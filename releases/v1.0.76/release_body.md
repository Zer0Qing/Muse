# Muse v1.0.76

本版本是一次面向稳定性、聊天效率、主题系统、朋友圈与小手机体验的综合更新。版本号为 `1.0.76`，versionCode 为 `176`。

## 稳定性与数据安全

- 补全数据库 89、90、91 版本迁移链，覆盖老版本升级到当前版本的多条路径。
- 增加迁移矩阵测试，降低老用户升级时出现 Room migration 缺链或 schema 校验失败的风险。
- 强化备份成功与失败提醒，恢复失败时提供专项错误信息和重试入口。
- 安全模式增加数据恢复引导，明确区分正常重启、清除数据和恢复数据操作。
- 增加聊天、输入区和会话列表的区域级错误边界，单一区域数据异常时不再拖垮整个页面。
- 修复部分网络、工具、流式生成和后台任务中的协程取消、异常恢复及重复触发问题。
- 优化图片、消息和导入数据的大小限制与落盘策略，降低大文件导致的内存峰值和设置文件膨胀风险。

## 聊天体验

- 新增全局命令面板，统一搜索会话、消息和常用命令入口。
- 新增会话内查找，支持命中计数、上一条、下一条、定位和高亮。
- 新增长会话消息地图，支持按消息位置快速跳转。
- 新增流式中插话和待发送消息队列，生成期间可以排队、编辑、删除或单独发送。
- 增强手动上下文压缩，支持保留条数和附加指令。
- 译文消息保留原文关联，可在消息内展开查看原文。
- 增量 Markdown 解析加入稳定节点缓存和 reduced-motion 降级，减少流式渲染抖动。
- 工具结果增加 JSON 树、DIFF、结构化表格和纯文本视图。
- 消息元信息增加模型、供应商、耗时和 token 信息查看。
- 宽屏设备支持会话列表与聊天内容双栏显示。
- 会话列表增加即时搜索和最近浏览历史。
- 完善消息多选、批量复制、分享和删除交互。

## 模型、工具与 MCP

- 增强 OpenAI 兼容供应商、Anthropic、Gemini 等模型适配和自定义请求模板。
- 修复部分模型首事件、模型名称、流式结束和多 Key 轮询问题。
- MCP 增加 SSE 断链保护、连接状态处理和国内常用工具模板。
- 飞书 MCP 支持基于 app_id/app_secret 的 tenant_access_token 缓存刷新，减少多设备互相顶掉 token 的问题。
- MCP 敏感凭证改为加密保存。
- 增强 Shell、浏览器、文件、网页抓取和子 Agent 工具的超时、沙箱及路径安全限制。
- 工具执行异常不再静默吞掉，增加更明确的错误记录和恢复路径。

## 主题与视觉

- 新增高对比主题，支持纯黑背景、纯白文字和更高对比度。
- 支持自定义主题 JSON 导入、导出和基于种子色生成完整配色。
- 支持导入第三方正文字体，并应用到全局界面。
- 新增聊天双色渐变背景，支持预设渐变、清除和背景图优先规则。
- 增加统一动效、列表入场动画、消息动画和 reduced-motion 适配。
- 继续收敛主题色、设计 token、触摸目标、图标无障碍描述和多语言资源。

## 朋友圈与小手机

- 朋友圈采用更接近微信朋友圈的信息流布局，优化封面、头像、消息中心、搜索和个人主页。
- 修复朋友圈分享、点赞、评论和收藏的交互与状态反馈。
- 点赞、评论和收藏按真实持久化结果更新，避免显示假成功状态。
- 朋友圈底部操作区与卡片长按手势隔离，提升点赞、评论和收藏按钮的点击可靠性。
- 小手机增加应用排序、隐藏应用、壁纸、相册收藏和隐藏等能力。
- 优化朋友圈图片、评论、消息中心和头像展示。

## 快速记录

- 增加应用内侧滑快速记录胶囊。
- 增加可选的系统悬浮窗快速记录，支持拖动、紧凑展开和退出 Muse 后使用。
- 悬浮窗改为小型 Chevron 胶囊，不再显示单个汉字。
- 系统悬浮窗跟随 Muse 当前主题颜色，支持黑白主题、自定义主题和动态主题。
- 快速记录卡片支持单击展开和收起正文，增加展开动画和状态提示。
- 编辑继续保留在记录的“更多”菜单中，不再要求用户为了阅读内容进入编辑页。

## 主动陪伴与每日总结

- 每日助手总结支持持久化，首页问候语可以显示今天或昨天的总结事项。
- 修复问候语首次加载时读取旧状态导致记忆事项不显示的问题。
- 近期事件提醒、生日提醒和问候语通知链路增加缓存与状态保护。
- 主动消息巡检增加日志、冷启动保护、深夜自主行动和更稳定的调度策略。
- AI 朋友圈、每日总结和日记生成内容统一剥离推理标签。

## 本地化与工程质量

- 补齐多语言资源并继续清理界面硬编码中文。
- 通过全量模块单测、静态门禁、detekt、ktlint、Lint、Kover 和 Debug/Release 构建验证。
- 保留三种 Release APK 产物：arm64-v8a、armeabi-v7a、universal。
