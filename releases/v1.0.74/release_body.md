## v1.0.74 更新说明

本版本是一次大规模质量修复版本：基于 16 路并行审计（覆盖全部 21 万行代码）修复 63 项问题，并处理了多位用户的真实反馈。

### 稳定性修复

- 修复发送队列消费者异常退出导致"队列已满，请稍后重试"、消息发不出去、会话切换卡死的问题（消费者协程永不死亡，异常自动恢复）
- 修复 DB 迁移缺失 capabilitiesJson 列导致老用户升级崩溃（新增 86→87 迁移）
- 修复搜索高亮空关键词时主线程死循环卡死
- 修复记忆中的非法生日文本（如"13月45日"）导致进入聊天页崩溃
- 修复进入非空会话时自动滚动覆盖"恢复位置/搜索定位"的问题
- 修复流式生成期间执行 /reset 导致对话断裂
- 修复 Android 14+（含 Android 16）上统计页平均时间格式串崩溃
- 修复长按消息菜单无锚点、收藏图标状态显示相反

### 数据安全

- 修复备份恢复（NDJSON 导入）无回滚保护，失败时数据库半清空的隐患
- 修复自动备份在 WAL 模式下可能丢失最近写入数据（改用一致性快照）
- 修复数据库降级/未知版本时静默清空全部数据（改为归档备份）
- 修复记忆数据库意外清空无备份的问题
- 修复加密笔记编辑时内容被永久清空、加密失败降级为明文的问题
- 修复删除消息后会话列表预览/计数残留的问题

### 安全加固

- 修复 subagent threadId 路径穿越，可写入应用私有目录任意位置的漏洞
- 修复 read_file 工具白名单被绝对路径绕过，可读取应用私有文件的漏洞
- 修复 read_public_file 可读取 file:// 私有文件的漏洞
- 修复局域网 Web 页面存储型 XSS 注入
- 修复群聊悄悄话内容在投票/总结/辩论中泄露给其他 agent 的问题
- 修复通知监听无差别采集敏感通知（验证码/银行等），增加 PII 遮蔽

### AI 与模型接入

- 修复 DeepSeek 官方 API 模型名不兼容问题（列表返回的带日期变体名被 API 拒绝，统一归一化为规范名）
- 修复多 Key 轮询并发修改崩溃
- 修复图片参考下载无超时/超大图片 OOM
- 修复生成完成事件重复发送、日志打印完整响应体可能泄露对话内容
- 修复视频生成自定义 API 地址不生效的问题
- 修复停止生成后仍发起降级请求浪费额度

### 主动消息与巡检

- 修复主动消息 24 小时保底机制永不触发的问题（主动消息长期不发）
- 新增主动巡检日志（记录每次巡检动作，防重复）
- 新增深夜自主行动（允许时段外安静写日记，不推送打扰）
- 修复 app_resume 重复触发巡检造成请求风暴
- 修复主动消息决策 JSON 被推理标签干扰解析

### 工具与并发

- 修复子 agent token 预算双倍消耗
- 修复 Shell 命令执行超时机制失效（可能永久阻塞）
- 修复 JS 沙盒并发执行无互斥、浏览器实例并发创建泄漏
- 修复网页抓取可访问内网地址（SSRF）
- 修复多线程吞掉协程取消信号导致停止按钮失效
- 修复任务重试使用截断参数导致必然失败

### 性能

- 修复朋友圈动态加载 N+1 查询（一次查询替代 100 次）
- 修复聊天背景图以 base64 写入偏好存储导致设置文件膨胀（改为文件存储）
- 修复 ChatGPT 导入大文件全量驻留内存导致 OOM
- 修复图片读取/解码无大小限制的 OOM 隐患

### 其他

- 修复多选删除无二次确认（误触即丢整段对话）
- 修复物理键盘多行输入时光标无法上下移动
- 修复记忆导出 JSON 转义不全导致非法文件
- 修复会话标题带 think 标签污染（全链路剥离推理标签）
- 修复 AI 日记/朋友圈动态/每日总结等生成内容被思考标签污染

### 技术说明

- DB 版本升至 87（86→87 增加 assistants.capabilitiesJson 列迁移）
- 新增 27 个单元测试（DeepSeek 模型名归一化、think 标签剥离、迁移链覆盖 87）
- 全量 978 个测试通过

### 安装

根据设备架构选择 APK：

- arm64-v8a：主流新设备（华为/小米/OPPO/vivo 等）
- armeabi-v7a：老旧 32 位设备
- universal：通用包（体积较大，不推荐日常使用）
