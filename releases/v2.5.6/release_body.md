# Muse v2.5.6

本轮集中修玻璃与子助手相关的问题，并统一顶栏形态。

## 液态玻璃

- **修复「关闭后仍有效果」**：玻璃开关之前只判断强度，不判断模式，导致「关闭」状态下只要强度不为 0 玻璃还在。现在模式为「关闭」即彻底关闭。
- **修复设置页无响应**：模式切换（关 / 水 / 磨砂）与强度滑条此前不真正生效，现已联动。
- **修复弹层玻璃**：更多菜单的黑遮罩与方形透明洞已修；加号菜单补上玻璃质感。

## 顶栏与输入栏

- **顶栏统一为一整块大岛**：单聊顶栏改为与群聊一致的形态，一条大岛含返回键 / 标题 / 更多键。
- **三种玻璃模式同形**：顶栏大岛形状不再随开关改变，只有材质随模式变化。
- **发送键改回纸飞机**：单聊、群聊统一。

## 修复

- **计划卡不再永久转圈**：工具循环异常结束、用户停止、或重新进入会话时，未完成步骤会落成「已取消」终态。
- **系统栏沉浸**：状态栏与导航栏改为真透明，页面内容延伸到手势条下方；关闭 Android 10+ 导航栏对比度遮罩，避免透明背景下多出一条暗条；窗口底色跟随主题。
- **底部面板沉浸**：加号菜单等底部面板铺到屏幕底，不再与屏幕之间露出一条窗口底色。

## 子助手

- **界面收敛为一处**：移除右侧贴边的浮动小窗和顶部的委派横条，子助手信息统一在对话流内的一条可展开任务卡中。

## 玻璃默认值

- **默认磨砂玻璃 68%**：新用户首次安装、以及从旧版本升级（此前未手动调整过玻璃）的用户，默认即开启磨砂玻璃、强度 68%。曾手动设置过的用户不受影响。

## 说明

- 数据库版本 110，与 v2.5.4 相同，直接升级不丢数据。
- 本包仅本地构建，用于真机测试，未发布 GitHub Release。
