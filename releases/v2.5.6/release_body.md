# Muse v2.5.6

在 v2.5.5 基础上补两项，并修好底部系统栏的适配。

## 系统栏沉浸

- **修复底部系统栏不适配**：此前主题里已声明状态栏/导航栏透明，但代码又把它们涂回不透明主题色，导致底部始终露出一条主题色（用户反馈的「小白条」）。现改为真正透明，页面内容与背景自然延伸到手势条下方。
- 关闭 Android 10+ 的导航栏对比度遮罩，避免透明背景下多出一条暗条。
- 窗口底色跟随主题，兜底未铺满全屏的页面。

## 液态玻璃默认值

- **默认改为磨砂玻璃 68%**：新用户首次安装、以及从旧版本升级（此前未手动调整过玻璃）的用户，默认即开启磨砂玻璃、强度 68%。
- 曾经手动设置过玻璃的用户不会被覆盖。

## 说明

- 数据库版本 110，与 v2.5.5 / v2.5.4 相同，直接升级不丢数据。
- 本包仅本地构建，用于真机测试，未发布 GitHub Release。
