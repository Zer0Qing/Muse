# Muse v1.0.89

- Tool execution hotfix: normalize built-in tool JSON schemas before resumed/background execution checks.
- Provider key rotation, HTTP safety, SSRF bridge, MCP startup, FileTools, Shizuku authorization, and Host WebSocket stability updates included from the audited workspace.
